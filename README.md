# Warhammer 40k Fan Page (React)

## Ejecutar

```bash
npm install
npm run dev
```

## Assets

Copia tus imágenes a `public/img/` con los mismos nombres que usabas en HTML:

- `Aquila-imperialis.png`
- `chaos-gods.jpg`, `space-marines.jpeg`, ...

## Rutas

- `/` = landing (facciones, galería, productos, contacto)
- `/products` = formulario de alta
- `/products?id=3` = edición
